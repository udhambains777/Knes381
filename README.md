## What You'll Find on the Site

My portfolio focuses on blending kinesiology concepts with technology. Some highlights include:

* **Python Data Analysis:** A computational computational tool built on Kaggle that analyzes testing data for VO2 kinetics and gas exchange to find crucial physiological boundaries like the Gas Exchange Threshold.
* **Programmatic Data Visualization:** An advanced athlete performance dashboard built dynamically in Excel, utilizing slicers to sort through and filter player metrics.
* **Technical & Logical Programming:** A custom-built, interactive multi-level Scratch maze game incorporating collision detection, timers, level progression, and anti-cheat systems. 
* **Biomechanical Video Analysis:** Video analysis and tracking of movement mechanics completed using Dartfish Express.
* **Computer Graphics:** Functional before-and-after image enhancement and editing using GIMP.
* **Academic CV:** A detailed overview of my educational background, volunteering, research, and professional experiences.
